# 📌 Project Overview
Tamil Cinema Insights 2012 to 2026 is an end-to-end Power BI analytics project that transforms Tamil movie data into an interactive and meaningful dashboard.

The dashboard is designed to understand:

- How Tamil movies perform across different years and genres
- How movie ratings and audience scores vary
- Which movies achieve the highest box office collections
- How movie budgets relate to box office performance
- Which movies are classified as Hit, Flop, Average, or Blockbuster
- How trailer views and people votes reflect audience engagement
- Which actors and directors have stronger movie performance
- How movie popularity changes over time
- How OTT platforms and target audiences compare
- How movie trends change across different release seasons and languages

The project uses data cleaning, Power Query, DAX, KPI calculations, and interactive Power BI visualizations to convert raw movie data into useful insights.

The final dashboard contains a Home page and 4 analytical pages, connected through interactive navigation, slicers, KPI cards, charts, and detailed tables.
# 🎯 Project Objectives
The main objectives of this project are:

1. Analyze the overall performance of Tamil movies from 2012 to 2026.

2. Understand movie ratings and audience response using IMDb Rating, Movie Rating, and Audience Score.

3. Analyze movie budgets and box office collections to understand financial performance.

4. Identify the Top 10 movies based on box office collection and IMDb rating.

5. Analyze Hit, Flop, Average, and Blockbuster movie performance.

6. Measure audience engagement using Trailer Views and People Votes.

7. Analyze movie popularity using the Popularity Index.

8. Compare movie performance across different genres, languages, actors, and directors.

9. Understand movie release and popularity trends across different years.

10. Analyze audience response across OTT platforms, target audiences, and release seasons.

11. Present the analysis through an interactive and user-friendly Power BI dashboard.

12. Provide clear and meaningful insights that help users understand Tamil cinema performance through data.

# 🖥️ Dashboard Structure

## 🧹 Data Preparation

The raw Tamil movie dataset was prepared and cleaned using Excel and Power Query before importing it into Power BI. The main goal was to improve data quality, maintain consistent data types, and make the dataset suitable for accurate analysis and visualization.

### Data Preparation Steps

- Removed the fully empty column from the dataset.
- Checked and handled missing values in important columns.
- Identified and reviewed duplicate records.
- Checked repeated movie names and validated them as required.
- Corrected inconsistent data types, especially in the Movie Name column.
- Converted numeric columns such as Budget, Box Office Collection, Runtime, and Ratings to appropriate data types.
- Ensured decimal values such as IMDb Rating, Audience Score, and Trailer Views were stored correctly.
- Reviewed inconsistent or unusual values in financial and performance-related columns.
- Standardized categorical fields such as Genre, Language, Hit Status, Profit Status, and Certificate Type.
- Applied appropriate formatting and rounding where required.
- Created calculated measures in Power BI using DAX for KPI and performance analysis.

### Tools Used for Data Preparation

- Microsoft Excel
- Power Query
- Power BI
- DAX

After completing the data preparation process, the cleaned dataset was loaded into Power BI to create interactive dashboards and meaningful insights.

## 📐 DAX & Analytical Calculations

DAX (Data Analysis Expressions) was used in Power BI to create calculated measures and KPIs for analyzing Tamil movie performance. These measures helped summarize movie ratings, financial performance, audience engagement, profitability, and popularity.

### Key DAX Measures Used

- 🎬 *Total Movies* – Calculates the total number of movies in the dataset.
- ⭐ *Average IMDb Rating* – Calculates the average IMDb rating of movies.
- 🎯 *Average Audience Score* – Measures the average audience response.
- 🏆 *Highest IMDb Rating* – Identifies the highest IMDb rating in the dataset.
- 📊 *Average Movie Rating* – Calculates the overall average movie rating.
- 💰 *Total Budget* – Calculates the total production budget of all movies.
- 🎬 *Total Box Office* – Calculates the total box office collection.
- 💵 *Average Budget* – Calculates the average movie production budget.
- 📈 *Average Box Office* – Calculates the average box office collection.
- 🏆 *Profitable Movies* – Counts the movies classified as profitable.
- 📊 *Hit Movies* – Counts the movies classified as hits.
- 🎯 *Hit Percentage* – Calculates the percentage of movies classified as hits.
- 📢 *Average Trailer Views* – Calculates the average trailer views in millions.
- 👥 *Total People Votes* – Calculates the total number of audience votes.
- 📈 *Average Popularity Index* – Measures the average popularity of movies.
- 🎭 *Average Hero Rating* – Calculates the average rating of lead actors.

### DAX Functions Used

The project mainly uses DAX functions such as:

- COUNTROWS() – To count movie records.
- SUM() – To calculate total budget, box office, and votes.
- AVERAGE() – To calculate average ratings, budgets, scores, and popularity.
- MAX() – To identify the highest rating.
- CALCULATE() – To calculate filtered metrics such as hit and profitable movies.
- DIVIDE() – To safely calculate percentages such as Hit Percentage.

These DAX measures were used across KPI cards, charts, tables, and other Power BI visuals to provide interactive and meaningful insights.

5. Refresh the dataset.

*Home → Refresh*

6. Explore the dashboard using the navigation buttons and interactive filters.
